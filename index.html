Aroma Diffuser AR Project

Goal: To show how a simple physical object can become more engaging inside an AR environment by responding to different scents with lighting, matching sounds, and real-time steam effects (Marketing of industrial products).

Tools: Unity, Vuforia (Image Target), C# Scripting.

Key Features: Interactive UI with tooltips, dynamic particle effects, audio integration, and real-time object manipulation (scaling & rotation).

Result: A smooth and responsive AR interaction on mobile that brings together visual and audio effects realistically.
